# one-rule-emergence
# 规则只许加一条 · 涌现实验室

> 每轮只加一条规则，秩序会从哪里出现？

《规则只许加一条》是一款围绕 “涌现” 主题制作的策略解谜游戏，也是聚光灯 Game Jam 的个人可玩 Demo。

你无法直接指挥每个机器人，只能逐轮为它们添加简单的行为规则。从寻找货物、送往出口，到交换货物、为伙伴让路，同一套规则会在不同地图中产生不同结果：有时形成持续运输的循环，有时让所有机器人堵在桥口。

观察问题、提出猜想，再用一条新规则改变局面，是游戏的核心体验。

🎮 游戏目标

在 六轮之内，让机器人把全部货物送到对应颜色的出口。

- 每轮只能新增一条规则，之前添加的规则会保留。
- 多条行动规则同时满足时，最新的一条优先执行。
- 货物交接独立生效，只有能够缩短合计送货距离时才会发生。
- 玩家可以暂停、单步观察，或回到本轮开始尝试另一条规则。

通关之后，还可以重试同一布局，挑战更少步数与更精简的规则组合。

 🧩 五张地图，五种问题

| 地图 | 设计重点 |
| --- | --- |
| 初始实验室 | 从找货与送货开始，建立持续搬运的循环 |
| 独木桥 | 面对对向拥堵，尝试通过货物交接解决问题 |
| 远近错配 | 最近的货物，是否意味着最高的运输效率？ |
| 环形仓库 | 在绕行、近道与相互阻挡之间寻找平衡 |
| 流水车间 | 观察传送带上的货物流动，让机器人完成接货与运输 |

推荐先体验 **初始实验室 → 独木桥 → 流水车间**，再进入其他地图自由挑战。

✨ 游戏特色

- **规则驱动的解谜**：通过改变行为规则，影响整个运输系统。
- **可以观察的协作**：查看机器人的目标、路径、生效规则与阻挡原因。
- **精选与随机布局**：精选场景突出机制，随机货物位置提供重玩变化。
- **布局编号复现**：在同一地图输入相同编号，可以重现相同开局。
- **低成本试错**：支持暂停、单步、撤销本轮和重试同一布局。
- **成绩与反馈**：记录同一布局的最佳成绩，并提供交接连线、送达动画与可选音效。

 🌱 关于“涌现”

游戏中的机器人只遵循简单的局部规则，并不了解完整的运输计划。

但当这些规则与地图空间、货物位置和其他机器人相互作用时，整体就可能出现新的行为：分工、交接、让路，也可能是争抢和拥堵。

游戏希望呈现的，正是这种从简单个体行为中逐渐形成整体秩序的过程。
